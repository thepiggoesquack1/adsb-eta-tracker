Privacy Policy

ADS-B ETA Tracker

Effective Date: July 2026

ADS-B ETA Tracker is designed with privacy in mind. The extension does not collect, transmit, store, sell, or share any personal information.

Information We Collect

ADS-B ETA Tracker does not collect user data.

The extension stores the following information locally on your device using Chrome's Storage API:

  • Configured destination name
  • Destination latitude
  • Destination longitude

This information never leaves your browser and is never transmitted to the developer or any third party.

How Your Information Is Used

The locally stored destination is used only to calculate:

  • Distance to the selected destination
  • Estimated Time of Arrival (ETA)

All calculations occur locally within your browser.

Data Sharing

ADS-B ETA Tracker does not:

  • Collect personal information
  • Upload user data
  • Sell user data
  • Share user data with third parties

Third-Party Services

ADS-B ETA Tracker does not use:

  • Analytics services
  • Advertising networks
  • Tracking technologies
  • Remote servers for processing user data

Permissions

The extension requests only the permissions necessary to:

  • Access ADS-B Exchange pages where the extension operates.
  • Store the user's configured destination locally using Chrome Storage.

Changes to This Privacy Policy

If this privacy policy changes in the future, the updated version will be published on this page.
